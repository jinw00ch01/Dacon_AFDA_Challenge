# Pro 기록 모음

> Pro 360(CPU 노트북)의 로컬 기록을 GitHub용으로 옮긴 것이다. 사용자 경로·장치 이름·계정 같은 개인 정보는 `<USER_HOME>`, `<pro-host>`, `<email>` 등으로 가렸다. 대회 원본·영상·가중치·토큰은 넣지 않았다.

| 파일 | 내용 |
|---|---|
| `pro_status_log.md` | Pro 에이전트의 로컬 상태 문서(docs/STATUS.md) 전체. 사이클마다 한 일, 근거 경로, 다음 할 일 |
| `pro_cycle_log.md` | agent_bridge 원장의 Pro 사이클 기록(시각, 깨운 이유, 비용, 요약) |
| `pro_operator_notes.md` | 운영자 세션 메모: 일시정지·재개, 리더보드 기록, 사람 작업 |
| `pro_human_actions.md` | Pro가 사람에게 요청한 작업 목록 |
| `pro_notes/` | main에 없던 분석 메모(S23 육안 확인, 게이트 역검증, Nexar triage 프롬프트) |
| `pro_tools/` | Pro의 독립 검증·분석 스크립트와 목록 |
