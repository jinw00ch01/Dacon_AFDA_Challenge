## Stage 3: 먼저 자동화

comma2k19 전체는 약33시간/2,019분 구간, 약100GB다. 처음부터 전체를 받지 않는다.
다음 확보 목표는 [공식 미러](https://huggingface.co/datasets/commaai/comma2k19/tree/main)에서
독립 주행5개 이상·총30~60분의 영상/CAN speed·steering/frame_times다. 아직 확보한 양은1분이다.
같은 원본 주행의 분 단위 구간은 같은 split에 넣고 최소2개 독립 주행을 검증용으로 남긴다.

이번 파일럿은 컨테이너25FPS와 센서 타임스탬프20Hz가 달랐다.
디코드1,200프레임과 frame_times1,200개를 일치 확인한 뒤 공통 boot-time으로 정렬했다.
외삽 없이10Hz599행을 만들었고 프레임 시각 오차 최대0.844ms였다.
`data/derived/pilot/comma_10hz_continuous.csv`에는 속도·조향각·속도 미분 가속도 proxy가 들어 있다.
공식 클래스는 아직 생성하지 않았다. 센서 부호·단위·필터·공식 임계값 확인 후 매핑한다.
현재1개 주행뿐이고 정지·급조향 다양성이 부족해 검증 성능을 측정할 자료로 쓰지 않는다.
CAN은 학습 타깃 생성에만 활용하고 제출 모델 입력은 영상으로 제한한다.
자동 확보·해시·시간 정렬 이후 사람이20개 표본과 급감속/회전 구간을 약30~45분 검수한다.

## Stage 2: 자동 후보 + 수동 정답

DoTA 작성자는 원 채널 공유 권한 확보를 설명하지만, 영상의 대회 사용·보고서 첨부 조건은 확인을 더 해야 한다.
이상 시작 시각은 실제 충돌/진입 정답과 다르다. CCD도 진입·방향·회피 정답을 모두 제공하지 않는다.

1. 이용조건 확인 후 자차 관여·옆 차선 진입 영상50~100개를 먼저 확보한다.
2. 다운로드·접촉 후보·차량 박스·프레임 미리보기·검수 CSV는 자동화한다.
3. 사람은 접촉/첫 차선 침범/진입 좌우/회피 공간을 공식 정의로 확인한다. 불확실 라벨은 미정의로 남긴다.
4. 같은 원본 YouTube ID·사고·재업로드·중첩 구간은 하나의 split group으로 묶는다.
5. 20%는 다른 검수자 또는 하루 뒤 자기 재검수로 확인하고 불일치를 기록한다.

`data/derived/pilot/stage2_review_queue.csv`에2,682개 후보를 만들었다.
대회 정답 열은 빈 값이며 모두 `unreviewed / video_not_acquired`다.
예산 추정: 영상당3~6분, 50개에2.5~5시간+재검수0.5~1시간, 200개에10~20시간+재검수2~4시간.
아직 완료된 라벨링이 아니다. 처음50개에서 가이드를 고정한 후 확대한다.

## Stage 1: 합성과 실제 재촬영

허용된 원본을 먼저 그룹 분할한 후 모아레·주사선·원근·반사·밝기·압축 파생을 생성한다.
seed와 변환을 기록하고 `synthetic_recapture`로 실제 촬영과 구분한다. 양 클래스의 코덱·해상도 분포를 맞춘다.
사람은 독립 원본24개를 두 노트북 화면에서 재생하고 S23 Ultra로 각2회 촬영한다. 준비·시험·전송을 포함해90분 배정한다.
실제 재촬영 검증셋은 훈련 원본과 분리한다. 물리적 촬영은 현재 도구로 대신할 수 없다.
